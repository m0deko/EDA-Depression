# Depression Text Analysis

## О проекте

В проекте выполнен комплексный разведочный анализ (EDA) текстового датасета Reddit для задачи бинарной классификации сообщений по наличию признаков депрессии.

Цель исследования — выявить статистические, лексические и семантические особенности текстов различных классов, а также определить признаки, наиболее полезные для последующего построения моделей машинного обучения.

Проект включает:

- загрузку и первичный анализ данных;
- предобработку англоязычных текстов;
- анализ распределения длин сообщений;
- исследование классово-специфичной лексики;
- анализ униграмм, биграмм и триграмм;
- TF-IDF-анализ;
- сравнение общей и уникальной лексики классов;
- анализ именованных сущностей (NER);
- формирование итоговых выводов.

## Основные этапы работы

1. Загрузка и исследование структуры данных.
2. Анализ пропусков и распределения классов.
3. Предобработка текста (токенизация, удаление стоп-слов, лемматизация/стемминг).
4. Анализ длины сообщений.
5. Исследование частотной лексики и N-грамм.
6. TF-IDF-анализ наиболее значимых терминов.
7. Анализ общей и уникальной лексики классов.
8. Анализ именованных сущностей (NER).
9. Формирование итоговых выводов.

## Основные результаты

В ходе исследования было показано, что:

- тексты с признаками депрессии в среднем длиннее нейтральных сообщений;
- эмоционально окрашенная лексика значительно чаще встречается в депрессивных текстах;
- N-граммы позволяют выявить устойчивые различия между двумя классами;
- TF-IDF выделяет наиболее информативные термины каждого класса;
- анализ именованных сущностей показывает лишь небольшие различия между группами;
- полученные результаты могут использоваться для дальнейшего построения моделей классификации текстов.
